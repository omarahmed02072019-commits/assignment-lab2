# Assignment Lab 2 — Responsive Component Library

## Files
- `index.html` — responsive component demo page
- `css/styles.css` — layout, form controls, CSS-only modal, alerts, and dark mode

## Run locally
Open `index.html` in a browser. No build tools or JavaScript are required.

## Requirements covered
- Responsive layout: one column on small screens, two columns at tablet widths (700px+), three columns on desktop (1000px+).
- Form components: labels, text/email inputs, select, textarea, and submit button.
- Modal window built with CSS only using a checkbox toggle; no JavaScript.
- Status alert/notification examples.
- Dark mode using `@media (prefers-color-scheme: dark)`.
- Basic semantic structure, visible keyboard focus styles, and labels for form controls.

## Before submitting
1. Open the site in Chrome and check the layout at mobile, tablet, and desktop widths.
2. Run Lighthouse in Chrome DevTools and review Accessibility. Fix any reported problems and aim for a score above 90.
3. Publish the project in a new GitHub repository if required by your instructor.
4. Submit the repository/site link using your course platform's instructions.

Note: a Lighthouse score depends on the browser/environment and must be measured; this project does not claim a guaranteed score.
